# 02 — 工業設計 / 結構尺寸規範（ID & Mechanical）

**Document ID:** XMX-T1-ID-001  
**適用：** 外觀設計、結構工程、模具、噴油絲印  

---

## 1. 設計原則【MUST】

1. **高級、簡潔、無過多裝飾線** — 對齊現有 XMX 品牌渲染（圓角充電倉、stem 耳塞）。  
2. Logo 僅使用字標 **XMX**（細線、寬字距、尖角 X）— 見 `drawings/LOGO_SPEC.md`。  
3. 禁止第三方方案原品牌絲印殘留。  
4. 開模前必須有：**3D STEP + 2D 尺寸 PDF** 雙方會簽。  

---

## 2. 兩種交付路徑（工廠二選一報價）

### Path A — ODM 現殼品牌化（首批推薦）【MUST 可報】

- 使用貴司現有模具殼  
- 改：顏色、噴油、鐳射/絲印 XMX、包裝  
- 尺寸 = 貴司 reference 圖（須提供）  

### Path B — 沿用 PCBA 新開殼【OPTIONAL 報價】

- 耳塞殼 + 倉殼按 XMX ID 新開  
- **內腔、針位、磁鐵、天線淨空必須匹配現有膽**  
- 品牌方出 ID；工廠出 DFM 與模費  

---

## 3. 外觀描述（ID Intent）

### 3.1 充電倉

| 項目 | 規範 |
|------|------|
| 形態 | 圓角矩形／鵝卵石感，上下蓋一體流暢 |
| 比例 | 可單手掌握；厚度避免臃腫 |
| 屏 | 上蓋外露或開窗（以方案）；黑片一體感 |
| 開合 | 阻尼適中，單手可開 |
| 正面 | 居中 **XMX** 字標（同色暗紋或淺鐳射） |
| 底面 | USB-C；可小型法規字（見包材） |
| 指示 | 優先用屏顯示；減少多餘燈 |

### 3.2 耳塞

| 項目 | 規範 |
|------|------|
| 形態 | Stem 式或方案成熟體；左右對稱 |
| 標記 | L / R 清晰 |
| 出音 | 硅膠套可更換 |
| 觸控區 | 外柄可觸；需防誤觸調校 |
| 外觀 | 與倉同色系；細縫均勻 |

### 3.3 CMF（顏色工藝）

| 代碼 | 效果 | 工藝建議 |
|------|------|----------|
| BK | 石墨黑啞光 | 噴油啞光 / 橡塑感 |
| CH | 香檳金 | 金屬漆細砂 |
| SV | 銀 | 細砂銀 |

- 色差：ΔE 以品牌方確認的 **色板（簽板）** 為準  
- 禁止粗糙層紋外露（量產注塑件）

## 4. 尺寸規範 — 分「可跟方案」與「硬約束」

> **精確 mm 以選定 ODM 方案 3D 為準。**  
> 下表為 **品牌方約束 + 人機目標**，工廠在 DFM 填實際值。

### 4.1 人機與體驗目標【TARGET】

| 項目 | 目標 |
|------|------|
| 單耳重量 | ≤ 5.5 g（不含套） |
| 倉重量 | 盡量 ≤ 60 g（含電池，方案限制內） |
| 倉外廓 | 可放褲袋；最長邊建議 ≤ 70 mm 級 |
| 耳塞套 | 含 S/M/L；中號預裝 |

### 4.2 硬接口約束【MUST — 改殼時】

若走 Path B 新殼，以下 **必須與現有 PCBA/針位一致**（由工廠出圖填數）：

| 接口 | 要求 | 工廠填寫實際值 |
|------|------|----------------|
| 充電 Pogo 針數量與間距 | 與 PCBA 完全匹配 | ___ mm |
| 針相對殼定位基準 | 標註於 2D | 圖號 ___ |
| 磁鐵位置/極性/吸力 | 保證方向防呆 | 吸力 ___ N |
| 天線淨空 | 禁金屬覆蓋區 | 見天線圖 |
| 喇叭前腔/後腔體積 | 不得無評估亂改 | 聲學確認 |
| 屏幕 FPC 長度 | 開合不拉扯 | ___ mm |
| 電池倉空間 | 含泡棉與絕緣 | 兼容 ___ mAh |

## 5. Logo 與絲印【MUST】

詳見 `drawings/LOGO_SPEC.md`。

| 位置 | 內容 | 工藝 |
|------|------|------|
| 倉正面 | XMX | 鐳射 / 暗色絲印 |
| 耳塞柄（可選） | XMX 或無 | 極細鐳射 |
| 倉內 | 無雜牌 | — |
| 電路板 | 可保留方案商料號（用戶不可見） | — |

**最小字高：** 倉外標誌建議 ≥ 3.5 mm 字高。  
**禁止：** 粗黑 logo、圓角卡通字、舊方案品牌名。
