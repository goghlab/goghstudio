## A. 我建議你點做（總戰略）

### 一句
**唔好一開始自己開模、自己編程、自己吹 Holo。**  
先做：**ODM 現成彩屏翻譯膽 + XMX 品牌皮 + 真機預售**；用 AI 團隊狂產內容同銷售資產。

### 三階段

| 階段 | 時間 | 你做咩 | 錢主要落邊 |
|------|------|--------|------------|
| **P0 驗證** | 第 1–4 週 | 落 2–3 家 ODM 樣、開 IG/官網 waitlist、AI 片測廣告 | 樣機 + 廣告小測 |
| **P1 預售** | 樣機到手後 2–6 週 | 真機片 + 早鳥預售 | 廣告 + 少量庫存訂金 |
| **P2 出貨迭代** | 首批出貨後 | 評價、T1 Pro 字幕功能、再考慮改殼 | 大貨 + 客服 |

### 明確「而家做」

## B. 推廣／預售：AI 片？網站？IG？

### 建議渠道組合（港亞小品牌最有效）

| 渠道 | 要唔要 | 作用 | 備註 |
|------|--------|------|------|
| **Instagram** | ★★★★★ 要 | 品牌門面、Reels、DMs | 主戰場 |
| **官網 Landing** | ★★★★★ 要 | 收集 email／預售／信任 | 一頁就夠 |
| **AI 短片** | ★★★★ 要（暖場） | 測文案、測賣點 | 收錢前要真機片 |
| **小紅書／抖音** | ★★★ 視人力 | 大陸／遊客 | 可第二步 |
| **YouTube Shorts** | ★★★ 複用 IG | 同一條片 | |
| **Google/Meta 廣告** | ★★★ 有片先投 | 精準旅遊興趣 | 小預算測試 |
| **Kickstarter** | ★★ 可選 | 國際曝光 | 交付壓力大，第二批再考慮 |
| **KOL 寄樣** | ★★★★ 有真機後 | 信任 | 旅行／日語／數碼博主 |

### AI 片 vs 真機片（好重要）

| 階段 | 用咩 | 可以講咩 |
|------|------|----------|
| 未有樣機 | AI 渲染 + UI 動效 | 「即將推出」「加入 waitlist」— **唔好寫已出貨** |
| 有 ODM 白牌樣 | 真機拍 + AI 包裝字幕 | 「工程樣測試中」 |
| 有 XMX 皮樣 | 真機為主 | 開早鳥預售 |
| 大貨 | 真機 + UGC | 正式賣 |

**規則：AI 片負責「靚同快」；真機片負責「信同收錢」。**

### 官網最簡結構（1 頁）
1. Hero：XMX Translate + 一句賣點  
2. 15 秒片（先 AI，後真機）  
3. 3 個場景：旅行／商務／日常音樂  
4. 規格摘要  
5. FAQ（延遲、語言、網絡）  
6. Email / 早鳥按鈕  
7. 頁腳：品牌、聯絡、退款政策（預售必寫）

### IG 內容柱（每週 5–7 條就夠）
1. **產品英雄**（倉屏翻譯特寫）  
2. **場景**（點餐、機場、會議）  
3. **對比**（望手機翻譯 vs 戴住 XMX）  
4. **品牌質感**（三色、開箱）  
5. **Social proof**（後續評價、KOL）  
6. **Behind the scenes**（選廠、測試—增加真實）

## C. 多重 AI 員工編制（你可以當「虛擬公司」用）

> 呢度唔係請真員工，而係 **固定角色 + 每次對話／每次任務用同一套 brief**。  
> 喺 Arena 你可以叫我「今日用 CEO + 內容總監 + 工廠 PM」同時產出。

### 組織圖

```
                    [你 = 創辦人 / 最終決策]
                              |
              +---------------+---------------+
              |               |               |
        [AI-CEO]        [AI-COO]        [AI-CFO]
        戰略定位         進度清單         成本/定價
              |
    +---------+---------+---------+---------+
    |         |         |         |         |
[品牌]    [內容]     [廣告]    [產品]    [客服]
 Design   Video/IG   Ads copy  Factory   FAQ/DM
```

### 角色說明（複製即用）

#### 1. AI-CEO｜戰略官
- **負責：** 定位、不賣咩、階段目標、風險  
- **產出：** 月目標、優先級、NO 清單  
- **你點叫：**「用 CEO 角色，只畀我 3 個本週最重要決策」

#### 2. AI-COO｜營運官
- **負責：** 30/60/90 日 checklist、依賴關係  
- **產出：** 今日 to-do、延誤預警  
- **你點叫：**「用 COO 更新進度表，標紅阻塞項」

#### 3. AI-CFO｜財務官
- **負責：** 樣機/MOQ/廣告預算、早鳥價、毛利  
- **產出：** 情景表（300/1000 台）、止損線  
- **你點叫：**「用 CFO 按 1000 台算，我最多輸幾多」

#### 4. AI-Brand｜品牌與設計總監
- **負責：** Logo 一致、視覺、包裝文案調性  
- **產出：** IG 版式說明、包裝字、色彩  
- **你點叫：**「用 Brand，出 9 格 IG 排版文案，跟 XMX 黑金風」

#### 5. AI-Content｜內容工廠（短片／Reels 腳本）
- **負責：** 腳本、分鏡、字幕、Hooks  
- **產出：** 15s/30s/60s 腳本；AI 片 prompt  
- **你點叫：**「用 Content 出 7 條 Reels 腳本，主題翻譯旅行」

#### 6. AI-Ads｜投放文案
- **負責：** 廣告 hook、A/B 文案、受眾假設  
- **產出：** Meta/IG 廣告 5 組  
- **你點叫：**「用 Ads 寫 5 組，目標 waitlist 登記」

#### 7. AI-Factory PM｜工廠項目
- **負責：** RFQ、規格、驗收、催樣  
- **產出：** 中英郵件、問題清單、QC  
- **你點叫：**「用 Factory PM 寫信問三家 ODM」  
- **已有文件：** `XMX_Factory_Package/`、`XMX_ODM_RFQ_Template.md`

#### 8. AI-Support｜客服與信任
- **負責：** FAQ、DM 回覆、預售條款  
- **產出：** 自動回覆模板、風險話術  
- **你點叫：**「用 Support 寫預售 FAQ，誠實講延遲同退款」

#### 9. AI-LegalLite｜合規提醒（非律師）
- **負責：** 宣傳紅線、預售免責、認證提醒  
- **產出：** 「唔可以講」列表  
- **注意：** 重要合約仍要真人律師

## D. 點樣「設立」呢啲 AI 員工（實操）

### 方法 1 — 喺 Arena 同我分工（而家就得）
每次開新任務用固定前綴，例如：

```
@角色: Content + Brand
任務: 出 IG 一週內容日曆
約束: XMX-T1 only；繁中；唔好承諾全息；港亞旅行客
```

```
@角色: Factory PM + CFO
任務: 比較三家 ODM 報價（我貼上報價）
產出: 建議選邊家 + 風險
```

### 方法 2 — 你自己建資料夾當「員工工位」
建議結構（已開始／可繼續擴）：

```
/XMX_Factory_Package/     ← 工廠員工
/XMX_Go_To_Market...md    ← 本文件
/XMX_Content/             ← 腳本、片、caption（可建）
/XMX_Ads/                 ← 廣告文案
/XMX_Brand/               ← logo 規範、色票
```

每個資料夾放：
- `BRIEF.md`（呢個角色永久任務）  
- `OUTPUT/`（產出）  
- `DONE_LOG.md`（做過咩）

### 方法 3 — 自動化（你有工具先上）
| 工具 | 用途 |
|------|------|
| 官方 IG + Meta Business | 發帖、廣告 |
| 郵件：Mailchimp / Brevo / 自建 | waitlist |
| 官網：Carrd / Framer / Shopify | 一頁 + 收款 |
| 剪輯：CapCut | AI 片加字幕 |
| 表格：Notion / Google Sheet | COO 進度板 |

**未有真自動化前，用「每週一同步」就夠：你 + 我（多角色）出齊一週物料。**

- Support 出 FAQ  
- 更新官網：真機圖替換 AI 圖

### Week 4 — 預售準備
- 金樣／品牌皮進度  
- 早鳥價鎖定（CFO）  
- KOL 短名單 10 個

## F. 預售點開先唔會翻車

| 做法 | 建議 |
|------|------|
| 先 waitlist 再收費 | ✅ 第一優先 |
| 早鳥付定金 20–30% | ✅ 有真機後 |
| 一開波全款 + 90 日後先出貨 | ⚠️ 要寫死風險同退款 |
| 淨 AI 片收錢 | ❌ 易被質疑 |

**預售頁必寫：** 預計出貨月、可能延誤、退款條件、聯絡電郵、產品係翻譯耳塞（網絡／準確率限制）。
