## 這個資料夾是什麼？

給 **ODM／模具廠／固件工程師／包材廠** 用的完整說明，讓工廠知道：

1. 產品要做成怎樣（功能、體驗）  
2. 外觀與品牌要怎樣（Logo、顏色、絲印）  
3. 尺寸與結構約束（哪些可跟方案，哪些必須符合）  
4. 軟件／UI／翻譯要怎樣寫  
5. 包裝、標籤、認證、驗收標準

## 重要聲明（給工廠）

1. **XMX-T1 優先採用貴司現有「彩屏充電倉 + 翻譯 TWS」成熟方案（ODM）**，再按本文件做品牌化與可改項。  
2. 標 **【MUST】** 的必須滿足；標 **【TARGET】** 為目標值可協商；標 **【TBD】** 須在選定方案後 5 個工作日內雙方書面鎖定。  
3. **未選定 platform 前，外殼精確 mm 以貴司 reference 模具為準**；品牌方提供 ID 方向與 logo 規範，開模前必須出 2D/3D 會簽圖。  
4. 任何減配、換芯片、換屏、換喇叭必須 **ECO 書面批准**，否則拒收。
