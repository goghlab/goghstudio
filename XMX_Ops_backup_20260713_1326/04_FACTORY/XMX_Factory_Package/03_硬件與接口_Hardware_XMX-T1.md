# 03 — 硬件與電子接口規範（Hardware）

**Document ID:** XMX-T1-HW-001  

---

## 1. 系統架構（邏輯）

```
[左耳 PCBA]--BT--[手機 App]
[右耳 PCBA]--BT--[手機 App]
     |                |
   入倉充電        雲翻譯 API（可選）
     |
[充電倉 PCBA + 彩屏 + 觸控 + 倉電池]
```

工廠須提供 **實際架構圖**（芯片型號一級）。

---

## 3. 電氣與充電【MUST】

| 項目 | 規範 |
|------|------|
| 倉輸入 | USB-C，5V；支持常見 5V1A 以上適配器 |
| 過充/過放/短路 | 保護板必須 |
| 耳塞充電 | 入盒自動；滿電指示 |
| 靜態功耗 | 息屏入倉長期存放不應週內耗盡（給出數據） |
| 充電時發熱 | 表面不燙手（≤ 約 45°C 體驗級，按安規測） |

---

## 4. 射頻【MUST】

| 項目 | 規範 |
|------|------|
| 頻段 | 2.4 GHz BT 合規 |
| 雜散 | 符合目標市場認證 |
| 改殼 | 若金屬漆/結構變化，需重評估天線 |

---

## 5. 聲學【MUST/TARGET】

| 項目 | 規範 | 級別 |
|------|------|------|
| 出廠 EQ | 提供曲線或聽感樣 | MUST |
| 最大聲壓 | 避免有害級；符合地區若有限制 | TARGET |
| 左右平衡 | 明顯不平衡為不合格 | MUST |
| 雜音 | 靜止無明顯底噪 | MUST |

若品牌方要求「XMX 調音」，列 NRE 與樣次。

---

## 6. 傳感器與按鍵

| 元件 | 用途 | 要求 |
|------|------|------|
| 入耳檢測 | 摘下暫停（若有） | OPTIONAL |
| 觸控 | 播放/翻譯 | MUST |
| 霍爾 | 開蓋出倉廣播 | TARGET |
| 倉鍵 | 配對/復位實體鍵可選 | OPTIONAL |

---

## 7. 生產與燒錄

| 項目 | 要求 |
|------|------|
| 固件燒錄 | 產線治具；版本號可追溯 |
| MAC / 序號 | 一機一號；盒外可掃描 |
| 校準 | 觸控、電量計、咪（若需） |
| 防呆 | 左右耳固件分料 |

序號規則建議：`XMX-T1-YYMM-XXXXX`

---

## 8. 可靠性（硬件）

| 項目 | 條件 | 合格 |
|------|------|------|
| 開關蓋 | ≥ 3000 次 | 功能正常 |
| 插拔 USB-C | ≥ 1000 次 | 正常充電 |
| 高溫存放 | 按 IPC/廠標 | 可開機 |
| 汗液/IPX4 | 淋水測試 | 通過 |

---

## 9. 禁用與安全

- 電池須有保護，禁止無保護軟包裸用  
- 符合 RoHS 有害物質限制  
- 附電池空運報告（UN38.3）大貨前提供
