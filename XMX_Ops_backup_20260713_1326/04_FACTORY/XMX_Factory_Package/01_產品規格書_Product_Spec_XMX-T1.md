# 01 — XMX-T1 Translate 產品規格書（Product Requirements & Spec）

**Document ID:** XMX-T1-PRS-001  
**Status:** For factory quotation & engineering  
**SKU:** XMX-T1  
**Marketing name:** XMX Translate  
**Category:** TWS earbuds with color-screen charging case + real-time AI translation  

---

## 1. 產品一句話

一對真無線耳機 + 彩屏充電倉：日常聽歌／通話，一鍵做 **中英日韓** 為主的實時翻譯；倉屏顯示原文、譯文與狀態。

---

## 2. 目標用戶與場景【MUST 理解】

| 場景 | 用戶行為 | 產品必須做到 |
|------|----------|--------------|
| 日本／韓國旅行 | 點餐、問路、購物 | 快速雙向短句翻譯 |
| 商務見面 | 兩人對話 | 低延遲、可看倉屏字幕 |
| 日常 | 音樂、電話 | 合格 TWS 體驗 |
| 送禮 | 開箱 | 高級包裝與 XMX 質感 |

**非目標（第一版不做）：** 醫療級助聽、會議 6 人同傳、耳塞內全息投影。

## 4. 功能規格總表

### 4.1 藍牙與連接

| 項目 | 要求 | 級別 |
|------|------|------|
| 藍牙版本 | ≥ 5.3（若方案僅 5.2 需聲明） | TARGET ≥5.3 / MUST ≥5.2 |
| 協議 | HFP / A2DP / AVRCP | MUST |
| 多點連接 | 雙設備為加分 | TARGET |
| 有效距離 | 空曠 ≥ 10 m | MUST |
| 回連 | 開倉自動回連手機 | MUST |
| 延遲（遊戲／視頻） | 低延遲模式可選 | TARGET |

### 4.2 音訊

| 項目 | 要求 | 級別 |
|------|------|------|
| 喇叭 | 方案商成熟單元；需提供單元尺寸 | MUST 披露 |
| 編碼 | SBC 必須；AAC 優先 | MUST SBC / TARGET AAC |
| 音樂體驗 | 中高音清晰，低音不過度糊 | TARGET（聽感會簽） |
| 通話 | ENC 雙咪或以上為優 | TARGET ENC |
| 音量 | 系統 16 級可調 | MUST |

### 4.3 主動降噪

| 項目 | 要求 | 級別 |
|------|------|------|
| ANC | 非必須；有則標明深度 | OPTIONAL |
| 通透模式 | 有則寫入說明書 | OPTIONAL |

> 首批可接受 **ENC 通話降噪、無 ANC**，以控制成本；若報價含 ANC 請分欄報價。

### 4.4 翻譯功能【核心 MUST】

| 項目 | 要求 | 級別 |
|------|------|------|
| 首批語言 | 繁中、簡中、EN、JP、KR 互譯組合 | MUST |
| 模式 A：聽譯 | 對方說話 → 譯文播入耳 + 倉屏顯示 | MUST |
| 模式 B：說譯 | 用戶說話 → 譯文播放／給對方聽（以方案能力） | MUST 至少一種說譯 |
| 模式 C：雙耳對講 | 一人一耳（若硬件支持） | TARGET |
| 觸發 | 倉屏一鍵 / App 一鍵；禁止複雜超過 3 步 | MUST |
| 在線翻譯 | 支持（Wi‑Fi／手機熱點／App 聯網） | MUST |
| 離線 | 核心語言離線包可選 | TARGET |
| 延遲 | 短句端到端目標 **≤ 1.5–2.5 s**（網絡正常） | TARGET |
| 準確率 | 日常旅行用語主觀可用；出廠抽測腳本見 QC | MUST 測 |
| 顯示 | 倉屏同時或切頁顯示 **原文 + 譯文** | MUST |
| 語言切換 | 屏上 2 次點擊內完成常用對（如 JP↔ZH） | MUST |

**翻譯引擎歸屬（須工廠書面說明）：**

- 引擎在 App 雲端 / 盒端 / 手機系統？  
- API 費用誰付？是否含首年？超量怎麼算？  
- 品牌方是否可替換為自有 API？【TARGET 可替換】

### 4.5 充電倉彩屏 UI【MUST 品牌化】

| 項目 | 要求 | 級別 |
|------|------|------|
| 屏幕 | 彩色；建議 ≥ 1.3–1.5" 級（以方案為準） | MUST 彩屏 |
| 觸控 | 點按／滑動 | MUST |
| 顯示內容 | 電量、藍牙狀態、翻譯模式、原文、譯文、語言對 | MUST |
| 品牌 | 開機／息屏／主頁含 **XMX** 字標（見 logo 規範） | MUST |
| 語言 | UI 支持 繁中 + EN（日文優先） | MUST 中英 |
| 亮度 | 室內清晰；可調為優 | TARGET |
| 超時息屏 | 可設 | TARGET |

### 4.6 電池與充電

| 項目 | 要求 | 級別 |
|------|------|------|
| 耳塞單次播放 | ≥ 4–6 h（音樂中等音量） | MUST ≥4 h |
| 倉+耳總續航 | ≥ 20–30 h | TARGET ≥24 h |
| 倉輸入 | USB-C | MUST |
| 充電顯示 | 倉屏或 LED 顯示充電狀態 | MUST |
| 電池認證 | 符合運輸與目標市場要求 | MUST |
| 倉電池容量 | 披露 mAh | MUST 披露 |

### 4.7 結構與防護

| 項目 | 要求 | 級別 |
|------|------|------|
| 耳塞防水 | ≥ IPX4 | MUST |
| 工作溫度 | 0–45°C | MUST |
| 左右識別 | 入盒方向防呆 + 標記 | MUST |
| 磁吸入盒 | 穩固，行走不甩出 | MUST |
| 重量 | 單耳盡量 ≤ 5.5 g 級（方案限制內） | TARGET |

### 4.8 操控（耳塞）

| 操作 | 默認建議 | 級別 |
|------|----------|------|
| 雙擊 | 播放／暫停 | MUST 可配 |
| 三擊 | 下一首 | TARGET |
| 長按 | 翻譯模式／喚醒 | 與方案協調 |
| 來電 | 雙擊接聽／掛斷 | MUST |

最終鍵位表在固件會簽時鎖定，並印入說明書。
